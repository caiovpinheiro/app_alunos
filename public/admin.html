Aula Inaugural

        Como gerar as imagens

        1. 1. Escolha as datas

          É a data de matrícula do relatório (EM CURSO). Uma data só = aquele dia. Vazio = todo mundo — só use se for isso mesmo.

        2. 2. Espere a conta

          Em cima aparece quantas pessoas entram. Em cada card: vamos criar é o que o botão gera agora; já têm já tem imagem. Pode demorar um pouco.

        3. 3. Gere o plano do semestre

          Não precisa sincronizar. Clique em Gerar planos e acompanhe “Gerando X de Y…”. A fila continua se o servidor reiniciar.

        4. 4. Matérias: sincronize, depois gere

          Sincronizar matérias atualiza a lista do SIAA. Sem isso o card fica 0. Só então clique em Gerar matérias.

        5. 5. Pronto quando aparecer “Geração concluída”

          “Ver todo o portal” só muda os números dos cards; o lote ainda usa as datas. CSV fica em Mais opções.
